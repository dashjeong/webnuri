# Webnuri · 웹누리 진단 워크벤치

Webnuri는 웹사이트 운영자가 지정한 누리집의 접근성, 검색 품질, 콘텐츠와 메뉴 구조를 점검하는 Windows 데스크톱 앱입니다. 측정 결과와 근거를 검토하고, 승인한 개선 카드를 보고서로 내보낼 수 있습니다.

## 첫 진단

1. **대상 관리**에서 진단할 누리집 이름과 시작 주소를 등록합니다. 비교할 사이트가 있으면 참조 대상으로 추가합니다.
2. **환경 설정**에서 사용할 모델과 호출 한도를 확인합니다. 외부 AI 기능을 사용하려면 해당 공급자의 자격 증명이 필요합니다.
3. **진단 만들기**에서 대상, 점검 항목, 기기, 페이지 수와 반복 횟수를 선택합니다. 예상 시간과 요청 범위를 확인한 뒤 실행합니다.
4. **진행·증거**에서 실제로 수집한 페이지와 측정하지 못한 범위를 확인합니다. **비교·검수**에서 근거를 검토하고, **개선·보고서**에서 승인 결과를 내보냅니다.

브라우저 실측에는 Windows x64와 설치된 Chrome 또는 Edge가 필요합니다. 사용자가 등록한 외부 사이트로 측정 요청을 보냅니다. 외부 AI 기능을 요청하면 선택한 근거 또는 기능에 필요한 입력을 설정한 공급자로 전송하며, 공급자 요금이 발생할 수 있습니다. API 키와 진단 데이터는 공개 저장소에 올리지 마세요.

프로젝트와 측정 기록은 사용자 데이터 폴더에 저장됩니다. 앱의 **파일 → 데이터 폴더 열기**에서 경로를 확인할 수 있습니다. 자동 측정 결과는 점검한 페이지와 조건에 해당하며, 최종 판단은 담당자가 근거를 확인해 내립니다.

## 점검 기준의 출처

검색 점검에는 행정안전부가 2024년에 공개한 범정부 UI/UX 디자인시스템(KRDS)의 검색 지침을 활용했습니다. 웹누리는 이를 자체 점검 항목으로 구성했습니다. 원자료 이용 조건은 공공누리 제1유형입니다. [KRDS 검색 지침](https://www.krds.go.kr/html/site/service/service_02_01.html) · [KRDS 저작권 안내](https://www.krds.go.kr/html/site/utility/utility_06.html)
